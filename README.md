📡 PAC System

The tool can display PAC URLs from your configured proxy source.

Example:

PAC URL
https://example.com/proxy.pac

Users can press:

📋 COPY PAC

to copy the PAC URL.

🔄 Auto Proxy

Proxy data can be loaded from a JSON/API source:

proxies.json

Example structure:

[
  {
    "country": "Singapore",
    "flag": "🇸🇬",
    "proxy": "IP:PORT",
    "pac": "https://example.com/proxy.pac",
    "status": "online"
  }
]

📱 Android WiFi Setup

WiFi → Network → Proxy → Proxy Auto-Config

Then paste the PAC URL.
